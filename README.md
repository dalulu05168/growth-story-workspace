# 投资者人物与交易工作台

这是一个 GitHub Pages 前端工作台，包含 70 位全量虚构法国投资者测试画像、人物分组、持仓与每日交易计划。

## 已实现

- 70 位人物完整画像载入、编辑、增加、删除。
- 系统分组与自定义小组。
- 进入动画、安全登录页、账户密码 + TOTP 2FA 本机认证流程。
- 主看板：人物总数、已开户、未入群、持仓人员、未持仓人员、今日待售、今日待买、自定义小组。
- 持仓管理：股票代码/名称、数量、买入价、买入时间、计划卖出时间、已售状态。
- 今日待售：按计划卖出时间自动计算并显示临近/到时提示。
- 今日待买：从已开户人员中按参与频率、是否持仓、用户强制参与设置与稳定随机分值生成。
- 看板卡片和待买/待售条目可跳转到对应模块和人物详情。

## 数据

默认人物数据位于 `data/people.json`。持仓、交易计划、自定义小组与人物修改继续保存在当前浏览器的 `localStorage` 中。

## 登录安全说明

当前部署为纯静态 GitHub Pages。已实现的账户密码 + TOTP 2FA 是浏览器本机认证模式，适合内部测试和单机使用。若要在公网自定义域名下作为正式多人系统使用，应把认证、会话、权限和敏感数据迁移到服务端身份认证/数据库。

## 自定义域名

仓库已经适配 GitHub Pages 自定义域名部署。拿到最终域名后，需要在仓库 Pages 设置与 DNS 中完成绑定，并创建对应 `CNAME` 文件。不要在没有最终域名时预写错误 CNAME。
