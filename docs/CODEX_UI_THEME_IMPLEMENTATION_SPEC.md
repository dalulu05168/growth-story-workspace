# 辰南撰写：当前 UI 与发布验收规范

更新于 2026-10-01。本文件是维护验收的当前入口。历史水墨/白灰/金黑改版提案保存在 `archive/UI_THEME_SPEC_2026-09.md`；其中的 1.4–2.2 秒品牌逐笔书写与全面深色编辑区尚未实施，不能视为当前版本已完成功能。当前按用户明确提供的黑金仙山参考图重做登录与开场。

## 当前主题

- 固定 `night` 星空金黑；移除登录页与工作台主题切换入口。
- 旧 URL 和存储偏好不改变当前主题；业务状态与认证流程不变。
- 登录背景使用 `assets/login/landscape.webp`，依据用户提供的黑金仙山参考图生成独立插画；真实登录控件不烘焙进图片。
- 电脑端优先，在 1280×720、1366×768、1440×900、1920×1080 检查表单可见和可操作。

## 当前进场动画

- `auth-intro-active` 触发整幅分层场景的 `cnBrand` 2.6 秒渐显，完成后登录卡片以 `cnLoginRise` 1.8 秒从下方浮出。
- 湖面使用 WebGL 纹理位移，缺失 WebGL 时使用 Canvas2D 波动；毛笔和比特币为独立透明图层，持续轻摆与轴旋转。
- 减少动态效果时冻结湖面、毛笔和比特币，卡片快速显示；登录成功隐藏层后释放 GPU / Canvas 动画资源。
- 生命周期 preparing → playing → complete → login-ready；真实 `animationend` 完成，7.6 秒兜底；资源准备最多 1.8 秒。
- “跳过动画”为真实可聚焦按钮；跳过动画仍须服务端认证。
- reduced-motion 快速显示；已有会话须恢复成功才解锁工作台。
- 成功登录时 `#authRoot.hidden` 必须完全隐藏，不得拦截工作台操作。

## 登录与云端请求

- 服务端校验账号密码并签发可撤销会话；不恢复历史二次验证码流程。
- 记住账号只保存用户名，不保存密码；显示密码按钮切换输入类型，忘记密码给出管理员重置指引。
- 表单标签关联输入框，错误使用 `role=alert`，提交按钮明确 `type=submit`。
- 测试必须点击提交按钮，不允许点击显示密码按钮后误认为已提交。
- 凭据错误显示服务端提示，工作台保持锁定，按钮重新可用。
- 网络失败、无响应、响应体停滞在 15 秒内结束等待并给出重试提示；超时会取消客户端请求。
- 不自动重试登录、保存或退出。保存超时仍保留本地修改，用户可再次保存；服务端如已处理写入，下一次版本冲突须走备份/恢复流程。
- 云端脚本缺失显示“登录服务未加载，请刷新页面重试”。

## 同一版本发布

- Vercel 与 GitHub Pages 都使用 `npm run build:static` 生成的 `dist/pages`。
- 仅发布入口引用的脚本、样式、默认人物资料、品牌/场景图和 CNAME；不发布服务端源码、测试账号文件或测试报告。
- `release.json` 记录源码提交与每个发布文件的 SHA-256。
- Pages 工作流先运行单元、静态门禁和本地登录前浏览器验收，再上传同一产物并快进更新 `gh-pages`，保留 CNAME 和历史，并显式请求 Pages 构建（机器人提交不会自动触发传统分支构建）。
- Vercel 使用 `vercel.json` 中的构建命令与输出路径。
- 发布后两处入口均须通过提交与全部发布文件（目前 36 个）哈希核对，允许短时 CDN 传播后重试，最终超时必须失败。
- 公网冒烟只提交随机不存在的账号并验证 HTTP 401；不得移除登录遮罩或注入业务数据来声称真实登录通过。

## 验证命令与边界

```bash
npm ci
npm test
npm run test:gate
npm run build:static
npx playwright install --with-deps chromium webkit
npm run test:prelogin
E2E_URL=https://nuvexapro.com/ npm run test:public-login
node scripts/verify-release.cjs https://nuvexapro.com/
```

`test:prelogin` 在本地静态产物启动服务器，以可控拒绝/停滞响应验证登录失败、超时重试、固定主题、密码显隐、用户名记忆、1280/1366/1440/1920 桌面尺寸、跳过动画和脚本缺失。它不证明云端正常账号登录成功。

真实登录后的 login/memory/navigation 阶段通过 `tests/current-e2e.cjs` 和受限 GitHub OIDC 隔离账号进行，执行后清理账号与合成测试数据。完整交易业务另由 `tests/business-e2e.cjs` 验收。管理员本人登录、全部业务和 Safari 必须用对应实测证据确认。

- 开场效果集中在 intro.css，使用 cn* 动画名；auth.js 仅同步完成事件名 cnBrand，认证与跳过流程不变。
