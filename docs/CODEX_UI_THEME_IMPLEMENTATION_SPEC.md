# 辰南撰写：当前 UI 与发布验收规范

更新于 2026-10-01。本文件是维护验收的当前入口。历史水墨/白灰/金黑改版提案保存在 `archive/UI_THEME_SPEC_2026-09.md`；其中的 1.4–2.2 秒品牌逐笔书写与全面深色编辑区尚未实施，不能视为当前版本已完成功能。本轮不根据未选择的 AI 概念稿重做界面。

## 当前主题与持久化

- `night` 星空金黑、`warm` 暖光书卷、`blue` 通透蓝白；兼容 `dark`、`ink`、`modern` 参数。
- 初始优先级：有效 `?theme=` → 手动选择 `chennan-theme-manual` → 旧 Pages 选择 `chennan-theme` → 首访轮换。
- 旧选择迁移到新键。URL 参数只临时覆盖，除非用户手动点击主题。
- 点击当前主题也应保存选择；下一次刷新、重新进入或重新登录保持该选择。
- 登录后沿用同一根节点主题；不复制业务逻辑。
- 存储不可用时界面仍能显示和切换，但不能承诺跨刷新保存。
- reduced-motion 立即切换主题，不等待淡出/淡入定时器。

## 当前进场动画

- 保留现有飞笔、轨迹、比特币与品牌的电影开场，正常动画约 6.4 秒。
- 生命周期 preparing → playing → complete → login-ready；`animationend` 完成，7.6 秒兜底；资源准备最多 1.8 秒。
- “跳过动画”为真实可聚焦按钮，跳过后仅解除动画等待，仍需要服务端认证。
- reduced-motion 和已有会话不等待完整开场；会话恢复成功才解锁业务。
- 登录品牌当前是文字，飞笔是独立图片/CSS 动画，不宣称实现了真实逐笔品牌 SVG。
- 日后实现历史短版设计，应同时更新时序规范与浏览器验收，而不是只修改图片。

## 登录与云端请求

- 服务端校验账号密码并签发可撤销会话；不恢复历史二次验证码流程。
- 表单标签关联输入框，错误使用 `role=alert`，提交按钮明确 `type=submit`。
- 测试必须点击提交按钮，不允许点击显示密码按钮后误认为已提交。
- 凭据错误显示服务端提示，工作台保持锁定，按钮重新可用。
- 网络失败、无响应、响应体停滞在 15 秒内结束等待并给出重试提示；超时会取消客户端请求。
- 不自动重试登录、保存或退出。保存超时仍保留本地修改，用户可再次保存；服务端如已处理写入，下一次版本冲突须走备份/恢复流程。
- 云端脚本缺失显示“登录服务未加载，请刷新页面重试”。

## 同一版本发布

- Vercel 与 GitHub Pages 都使用 `npm run build:static` 生成的 `dist/pages`。
- 仅发布入口引用的脚本、样式、默认人物资料、品牌/场景图和 CNAME；不发布服务端源码、测试账号文件或测试报告。
- `release.json` 记录源码提交与每个发布文件的 SHA-256。
- Pages 工作流先运行单元、静态门禁和本地登录前浏览器验收，再上传同一产物并快进更新 `gh-pages`，保留 CNAME 和历史，并显式请求 Pages 构建（机器人提交不会自动触发传统分支构建）。
- Vercel 使用 `vercel.json` 中的构建命令与输出路径。
- 发布后两处入口均须通过提交与全部发布文件（目前 19 个）哈希核对，允许短时 CDN 传播后重试，最终超时必须失败。
- 公网冒烟只提交随机不存在的账号并验证 HTTP 401；不得移除登录遮罩或注入业务数据来声称真实登录通过。

## 验证命令与边界

```bash
npm ci
npm test
npm run test:gate
npm run build:static
npx playwright install chromium
npm run test:prelogin
E2E_URL=https://nuvexapro.com/ npm run test:public-login
node scripts/verify-release.cjs https://nuvexapro.com/
```

`test:prelogin` 在本地静态产物启动服务器，以可控拒绝/停滞响应验证登录失败、超时重试、主题刷新、375/390/414/430/1366/1440/1920 宽度、跳过动画和脚本缺失。它不证明云端正常账号登录成功。

真实登录后的 login/memory/navigation 阶段通过 `tests/current-e2e.cjs` 和受限 GitHub OIDC 隔离账号进行，执行后清理账号与合成测试数据。完整交易业务另由 `tests/business-e2e.cjs` 验收。管理员本人登录、全部业务和 Safari 必须用对应实测证据确认。

## 2026-10-01 景深与动画更新

- 开场效果集中在 intro.css，使用 cn* 动画名；auth.js 仅同步完成事件名 cnBrand，认证与跳过流程不变。
- 减少动态效果时关掉光束、光尘、黑边和模糊，登录区快速显示。
- workspace-glass.css 负责侧栏、顶栏及卡片玻璃景深；不支持背景模糊时使用实色表面。
- 工作台在 app-ready 后分层进入，不变换整个 app，移动端固定导航保持以视口定位。
- 本地视觉验收通过登录表单和模拟云响应进入，不移除认证遮罩、不注入会话；正式环境继续使用隔离账号验收。
